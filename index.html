HellSprint is a Fast Paced first person shooter where one aims to survive through an increasing difficulty of swarms of enemies. Survive long enough and gain a ranking in the leaderboard, and prove you’re the best player out there.

I worked as the lead programmer of HellSprint, focusing on the core gameplay loop and the managers responsible for coordinating the game's systems. This was an academic project during our third year, where I worked on integrating SQLite with Unity to demonstrate the engine's capability to work with SQL databases.

RetroBaseballDX is a simple baseball game with a retro 2D pixel artstyle and a simple gameplay loop. Score as much points and homeruns before you are out.

This is a personal project of mine and a creative practice project, i was inspired by the old SNES system and how simple yet enjoyable the gameplay loops of older games could be. I emulated the system by working on the game with intentional constraints or limitations, more specifically, limited art, a limited number of systems, and strict use of event systems to keep the game simple and focused.

FuniCow Slideeeee is a endless sliding game where you control an escaped cow from it's impending butcher doom.
Perform tricks to gain speed and points to upgrade your run.

BleakRidge

BleakRidge is a PSX-styled horror game that combines cute characters with dark and twisted humor. Set in a fictional location called BleakRidge, you are a recent newcomer in the town who soons discovers something is wrong with the town. Investigate the mysterious cult and uncover the lies beneath.

Projects

Other projects i've worked on, softwares, tools,

ManuVox | Unity . C# . MediaPipe . Java

I’m the lead developer of ManuVox, an offline Filipino Sign Language recognition application built with Unity and C# for Android. I worked on the real-time gesture recognition system using MediaPipe, gesture logic, ScriptableObjects, Addressables, and Android Text-to-Speech, with Java integration for native Android functionality.

Carbonet | PHP . MySQL . Javascript . Python . Pytorch

Carbonet is a greenhouse gas emissions calculator built to process categorized environmental data and generate emission results based on defined metrics. I helped develop the web system alongside IoT device development and integration, working with PHP, MySQL, HTML5, Tailwind CSS, JavaScript, Python, OpenCV, and PyTorch, including a Temporal Fusion Transformer analytics engine.

Win98Chat | Node.js · Express.js · REST API · Socket.IO

Win98Chat is a recreation of the old MSN Messenger experience from the Windows 98 era. I used Node.js, Express, and Socket.IO to power the web app's real-time messaging features. You can invite your friends to try it out, chat anonymously, and play around with the retro-inspired messenger.

LyricsFinder | HTML . CSS . Javascript . RestAPI

LyricsFinder is a project I worked on because I found it slow and difficult to find lyrics for less common songs. I used the Lyrics.ovh API to search and retrieve lyrics, and designed the interface around the visual language of Windows 95 to make it more appealing and easy to understand.
